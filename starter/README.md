# SimpliShop starter

This is the course baseline: a complete React electronics store with local catalog, search, filters, product details and a working cart. It does not include WebMCP registration or the developer workbench.

```sh
npm install
npm run dev
```

The starter intentionally includes `products.ts` and `cart.ts` as readable foundations for implementing the tools during the course. See `../course-docs/04-COURSE-LESSONS.md` for the lesson sequence.
